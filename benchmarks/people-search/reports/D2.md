- **The plan's gap is 10 minutes** between cycles. Production runs cycles hourly; the shorter gap was agreed earlier. Only learning on's cycle 1 finished first (in 7 minutes). The other 3 cycles were still checking prospects when the next one started, so their lessons could not inform it. That is why "learning has time" fails.
- **It does not affect the main run.** The main run uses first cycles only, with no learning between cycles.
- **It does affect stage 2.** A fixed gap is not enough, since two cycles here were still running after 90 minutes. Before stage 2, make the next cycle wait until the previous cycle's checks and lessons are done. Add a time limit for a cycle that never settles, and report it.

## 4. What changed during the pilot

- **Prompt 1 only.** Plan amendment, 20 Nov: prompt 6's first cycle moves to the main step, which now runs 18 first cycles.
- **2 cycles per condition, not 4.** Learning on timed out in cycle 2. Learning off was interrupted in cycle 2 and resumed to finish that cycle. A stopped workspace cannot start new cycles.
- **Learning on's cycle 2 ran on code from before the cap fix.** The fix is deployed for everything after it.
- **Learning off was resumed twice.** Costs before and after each stop are combined, and they also appear separately in the run report.
- **Account plan.** On 20 Nov the dev benchmark account was moved to the free plan, which blocked the resume. It was set back to Pro on dev only, with a 14-day tester grant.
- **One judge call returned no output.** It was rerun for $0.01.
- **Found while checking the run: no rejected prospects were judged.** The plan judges 3 of ReacherX's rejected prospects per cycle, to catch matches it wrongly turned down (proposal 5.7). The pilot judged 0 of a planned 12.
  - Cause: the harness only samples rejected prospects typed as people. ReacherX types a prospect only when it accepts it, so all 1,210 rejected prospects have no type.
  - Fix (benchmark only): sample untyped rejected prospects too, and let the judges decide. Judging the pilot's 12 would cost about $0.06.
- **The cap fix has not been tested live yet.** After the fix, no cycle reached 20 matches, so the main run will be its first real test. The approval caps stay as hard stops.
