Some things are easier to say out loud. A quick thank-you. An answer that would take a while to type. An idea you want to explain in your own words.

You can record and send voice notes from supported X and LinkedIn conversations in ReacherX. It's your own recording, using your microphone.

On LinkedIn, start with someone you're already connected to. [LinkedIn limits voice messages to those connections and group chats](https://www.linkedin.com/help/linkedin/answer/a548233/recording-voice-messages-sent-on-the-linkedin-mobile-app?lang=en). This guide uses an individual conversation.

## Record a note

1. Open the person's conversation in ReacherX.
2. Choose the voice recording control in the message composer.
3. Allow microphone access if your browser asks.
4. Record your note, then stop and listen to it.
5. Send it when you're happy with it, or discard it and try again.

Keep it short. If you lose track of the point halfway through, another take is usually better than making the listener work it out.

## A few limits to know

On LinkedIn, a voice note can be up to one minute long. It goes as a separate message, so send any text introduction separately.

On X, you need to unlock your X Chat session first. If you don't see the recording control, check the chat connection.

Recording is available in the normal conversation composer. You won't see it in the composer used to approve an agent's outreach task. Open the conversation itself to record a note.

## Give someone a reason to listen

A voice note can be useful when you're already talking. An unexpected recording from a stranger is a bigger ask.

A short text first can help: “I had an idea about the workshop you mentioned. Is it okay if I send a quick voice note?” If they prefer text, use text.

If recording doesn't work, check your browser's microphone permission and chosen microphone. If sending fails, read the error before trying again. Check the conversation so you don't accidentally send the same note twice.

For the rest of the messaging controls, see [how to read and reply to DMs](/blog/manage-dm-conversations). If the person needs to see something as well as hear it, [send a short video](/blog/outreach-with-images-and-video).
